# 历史价值来源准入：本轮结论

取得了两类新增来源证据，尚未形成全量估值或利润账。

1. API3固定119个E收款hash全部取得完整JSON对象，共128条清算；与原receipt清算log及资产/borrower地址匹配。对象有USD估值、gasCostUsd和nativeTokenPrice，但无每资产原始数量、精度、独立价格来源或价格观测时间。262笔费用hash中仅119笔在保存前缀出现完整对象，另143笔未观察到，不等于完整响应不存在。
2. 独立DefiLlama源在默认案例时间请求下，返回mETH精确合约和MNT候选标识的完整历史price/time/confidence记录。两条返回时间都晚于交易时间，因此不能称为精确当时价格；本轮未添加价格时间容差或选价规则，也没有覆盖全119/9资产及262费用时点。
3. API3整体响应因本轮8MiB单体上限截断，119目标对象已完整取得不因此作废。公开动作6/6，网络停止；截断不是来源拒绝、付费墙或永久无数据。原始失败、成功、截断、完整对象定位、字段和全部哈希均保存。

此轮只做来源、符号维度和身份覆盖核验，未乘数量、除数推价、汇总USD、计算净利润或运行模型/交易。免费公开历史价值数据并非一概不可得；当前未桥接的是全量覆盖、价格来源/时间口径和完整经济账边界。

详见API3-source-admission.md、独立历史价格源-默认案例准入.md及各源回执；全部输出路径与哈希见final-delivery-manifest.json。actual model/effort UNKNOWN。
